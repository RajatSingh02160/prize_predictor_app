Dynamic Parking Price Predictor

This AI-powered web application predicts parking prices based on real-world parking conditions. The prediction depends on:

  • Occupancy → Number of parking spots currently occupied
  • Queue Length → Number of vehicles waiting for parking
  • Special Day → Whether the day is a festival, holiday, weekend event, or high-demand day

The model uses Machine Learning to dynamically adjust parking prices according to demand. Higher occupancy, longer queues, and special events usually increase parking prices.

Input Guide

  • Occupancy: Enter value between 0–100
  • Queue Length: Number of vehicles waiting
  • Special Day:
    • 0 = Normal Day
    • 1 = Special/Event Day

Example

Example Input:

  • Occupancy = 85
  • Queue Length = 10
  • Special Day = 1

How the Model Understands Pricing

Occupancy vs Parking Price

Higher occupancy generally increases parking prices because demand becomes higher.

Queue Length vs Parking Price

Longer queue length indicates higher demand, so prices tend to rise.

Special Day Effect on Price

Special days such as festivals or events usually increase parking demand and pricing.
